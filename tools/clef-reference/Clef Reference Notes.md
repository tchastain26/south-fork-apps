# Clef Reference Notes

Created: 2026.05.09
Status: Done

## What It Does

Complete treble and bass clef note reference with SVG-rendered staves showing all natural notes from the bottom of the bass clef to the top of the treble clef (including ledger lines). Each note shows its name below the note head. Includes four mnemonic sections (treble/bass lines, treble/bass spaces), and a ledger line quick reference table covering middle C, C3, A5, G2, and other common out-of-staff notes.

## How to Use

Use the stave diagrams to locate any note, the mnemonics to memorize positions, and the ledger line table for out-of-staff notes.
