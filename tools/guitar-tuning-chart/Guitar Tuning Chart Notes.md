# Guitar Tuning Chart Notes

Created: 2026.05.09
Status: Done

## What It Does

Reference chart for 18 standard and alternate guitar tunings grouped by category: Standard, Drop, Open, and Modal/Other. Each card shows the tuning name, a description, and individual string notes (low to high). Changed strings (compared to standard EADGBE) are highlighted in green.

## How to Use

Use the filter buttons to narrow by category. Hover cards for highlight effect.
