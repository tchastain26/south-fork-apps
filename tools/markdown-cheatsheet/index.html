Markdown Cheat Sheet

Markdown Cheatsheet is a complete syntax reference with live examples: headings, emphasis, links, images, lists, code, blockquotes, tables and more, each shown as source and as rendered output.

The syntax worth memorising

Most of Markdown is six or seven patterns. Hashes for headings, asterisks or underscores for emphasis, square brackets and parentheses for links, hyphens or numbers for lists, backticks for code, and a greater-than sign for quotes.

The rules that catch people out are about blank lines. A paragraph ends at a blank line, a list needs one before it in many parsers, and a fenced code block needs its opening and closing fences on their own lines.

When it helps

  • Looking up syntax you use rarely, like reference-style links or nested lists.
  • Learning Markdown by seeing source and output together.
  • Checking which features are core Markdown and which are extensions.
  • Keeping a reference open while writing documentation.

What this tool handles

  • Every example shows the raw syntax next to the rendered result.
  • Covers both core Markdown and the common GitHub Flavored extensions.
