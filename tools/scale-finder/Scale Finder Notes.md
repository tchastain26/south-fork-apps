# Scale Finder Notes

Created: 2026.05.09
Status: Done

## What It Does

Comprehensive scale reference tool. Select any root and one of 15 scale types (major, all modes, pentatonic, blues, harmonic minor, melodic minor, whole tone, diminished, chromatic). Shows all scale notes as labeled cards, highlights the scale on a one-octave piano keyboard, displays an interval table with degree, note name, interval name, and semitone count. Play button arpeggios the full scale via Web Audio.

## How to Use

Select root and scale type. Note cards and piano update instantly. Hit Play to hear the scale ascending.
