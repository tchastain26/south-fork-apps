# Chord Finder Notes

Created: 2026.05.09
Status: Done

## What It Does

Reverse chord lookup tool. Click any notes on a two-octave piano keyboard to select them (multi-select). The app identifies all matching chord names using a chord detection algorithm that tests every selected note as a potential root and matches against 21 chord definitions. Shows chord name, type, inversion, and interval structure. Clicking a note also plays it via Web Audio.

## How to Use

Click notes on the piano to build a chord. Selected notes show in green, and matching chord names appear below. Click the same key again to deselect. Clear button resets.
