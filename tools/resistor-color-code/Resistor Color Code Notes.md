# Resistor Color Code Notes

Created: 2026.05.23
Status: Done

## What It Does

Resistor Color Code decodes 4-band and 5-band resistors by turning selected stripe colors into a resistance value, multiplier, tolerance, and expected measurement range, while also showing a live resistor preview and quick reference table.

## How to Use

Choose 4-band or 5-band mode, then select each band color from the dropdowns. Review the decoded resistance, tolerance, min and max range, and the live resistor illustration to confirm the stripe order.
