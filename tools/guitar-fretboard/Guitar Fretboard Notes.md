# Guitar Fretboard Notes

Created: 2026.05.09
Status: Done

## What It Does

Interactive guitar fretboard showing all note names across 6 strings and 12 frets. Supports scale highlighting (Major, Minor, all modes, Pentatonic, Blues, Harmonic Minor) and multiple tunings (Standard, Drop D, Open G, DADGAD, Eb Standard). Root notes show in bright green, in-scale notes in muted green, out-of-scale notes hidden. Fret markers at 3, 5, 7, 9, 12.

## How to Use

Select a root note, scale type, and tuning. The fretboard updates immediately. Set root to "None" to see all note names without scale filtering.
