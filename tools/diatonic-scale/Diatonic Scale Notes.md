# Diatonic Scale Notes

Created: 2026.05.09
Status: Done

## What It Does

Comprehensive diatonic scale reference for any major key. Select a root to see: all 7 scale notes with degree labels, all 7 diatonic triads with chord names / Roman numerals / quality / notes / harmonic function, all 7 diatonic seventh chords with names and notes, and all 7 modal rotations with starting note, mode name, scale notes, and character description.

## How to Use

Select a key from the dropdown. All three tables update immediately. Covers all 12 major keys with correct enharmonic spellings (sharps vs flats).
