# CSS Specificity Calculator Notes

Created: 2026.05.22
Status: Done

## What It Does

Calculates the (A, B, C) specificity score for any CSS selector. Enter one or multiple selectors separated by commas to compare them side by side. Shows score breakdown by IDs (A), classes/attributes/pseudo-classes (B), and type selectors (C), plus a visual bar chart when comparing. Handles :not(), :is(), :has(), :where(), pseudo-elements, attribute selectors, and combinators.

## How to Use

Type or paste a CSS selector and press Enter or click Calculate. Click quick-example buttons to prefill common patterns. Add multiple selectors to rank them by specificity. Click × to remove any row.
