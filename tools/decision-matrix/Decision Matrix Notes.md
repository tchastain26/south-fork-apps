# Decision Matrix Notes

Created: 2026.05.24
Status: Done

## What It Does

This app helps compare multiple choices using weighted criteria and live scoring totals. It supports editable criteria, adjustable weights, option-by-option scores, ranked results, total percentages, and a quick way to see which criterion is driving each option’s score.

## How to Use

Edit the criterion names and weights, rename the options, then enter scores from 0 to 10 in the matrix. The ranked results update automatically. Use Add Criterion or Add Option to expand the matrix, and Load Example if you want a clean sample to start from.
