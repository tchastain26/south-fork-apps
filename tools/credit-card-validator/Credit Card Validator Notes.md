# Credit Card Validator Notes

Created: 2026.05.03
Status: Done

## What It Does

Validate card numbers using the Luhn algorithm and detect card type. Visa, Mastercard, Amex, and more. Free tool.

## How to Use

Open the app in a browser. No account or install required — everything runs locally.
