# UUID Generator Notes

Created: 2026.05.04
Status: Done

## What It Does

Generates UUID v4 and UUID v7 values in the browser with batch output and quick formatting options. It supports uppercase output, optional braces, and hyphenless IDs so the result can be dropped straight into code, database seeds, or test fixtures.

## How to Use

Choose the UUID version, set how many IDs you want, and toggle any formatting options. Generate a fresh batch, then copy one ID at a time or copy the whole list at once.
