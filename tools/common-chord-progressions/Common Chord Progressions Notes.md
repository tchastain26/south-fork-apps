# Common Chord Progressions Notes

Created: 2026.05.09
Status: Done

## What It Does

Reference library of 20 common chord progressions across 6 genres (Pop, Rock, Blues, Jazz, Folk, Classical). Select any key and Major/Minor mode to see chord names alongside Roman numerals. Each progression card shows the name, genre tags, transposed chord names, description/context, and a "Hear it" button that plays the progression via Web Audio. Filterable by genre.

## How to Use

Select key and mode, filter by genre, browse progressions. Click "Hear it" to play an audio preview of the chord sequence.
