# Overtone Series Notes

Created: 2026.05.09
Status: Done

## What It Does

Visual and interactive overtone series explorer. Select a fundamental note (any of 12 chromatic notes) and octave. Displays up to 16 partials showing: harmonic number, frequency ratio, exact frequency in Hz, nearest equal-temperament note name, cents deviation from equal temperament (colored green if within 10 cents, red if not), and interval name relative to fundamental. A bar chart visualization shows relative amplitude. Click any row or bar to hear that partial. Play Series button plays all partials simultaneously.

## How to Use

Select fundamental note and octave. Adjust number of partials. Click any row to hear that partial, or Play Series to hear all at once.
