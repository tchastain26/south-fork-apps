# HTTP Status Codes Notes

Created: 2026.05.22
Status: Done

## What It Does

Complete searchable reference for all standard HTTP response codes (1xx through 5xx). Covers 60 codes with descriptions, practical notes, and common fix hints. Filter by category or search by code number, name, or any keyword.

## How to Use

Type any code number (e.g. 429), name (e.g. "timeout"), or keyword (e.g. "rate limit") in the search box. Use the category buttons to filter by response class.
