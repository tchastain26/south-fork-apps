# Scientific Notation Converter Notes

Created: 2026.05.22
Status: Done

## What It Does

Converts any number (decimal or e-notation) to scientific notation, pretty × 10^n form, engineering notation (exponent multiple of 3), SI prefix notation, and standard decimal. Click any row to copy. Quick-example buttons for common physics constants.
