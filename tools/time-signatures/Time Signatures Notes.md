# Time Signatures Notes

Created: 2026.05.09
Status: Done

## What It Does

Comprehensive time signature reference covering 7 common meters: 4/4, 3/4, 6/8, 12/8, 2/4, 5/4, and 7/8. Each card shows the time signature symbol, name, beat visualization (strong/medium/weak coded by border color), grouping description, feel tags (Pop, Jazz, Blues, etc.), and a Count In button that plays the beat pattern via Web Audio with visual highlighting. Also includes a note values reference grid at the top.

## How to Use

Read beat groupings from each card. Click "Count In" to hear 2 bars of the time signature at 100 BPM with the beats highlighted.
