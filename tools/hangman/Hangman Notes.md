# Hangman Notes

Created: 2026.05.24
Status: Done

## What It Does

Hangman is a browser-based word guessing game with built-in category packs, three difficulty levels, keyboard support, and persistent win streak stats stored locally in the browser.

## How to Use

Choose a category and difficulty, then guess letters using the on-screen keyboard or your physical keyboard. Correct guesses reveal every matching letter, wrong guesses cost a life, and the New Word button starts another round.
