# CSS Clamp Generator Notes

Created: 2026.05.04
Status: Done

## What It Does

Generates fluid CSS `clamp()` formulas from viewport breakpoints and size targets. It outputs both pixel and rem versions, shows the slope and intercept, and includes a live preview so you can see the scale before copying the CSS.

## How to Use

Set the minimum and maximum viewport widths, then enter the minimum and maximum sizes you want. Adjust the root font size if you need rem output, then copy the clamp formula or full CSS rule from the result panel.
