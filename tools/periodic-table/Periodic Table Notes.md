# Periodic Table Notes

Created: 2026.05.24
Status: Done

## What It Does

This is a single-file interactive periodic table with all 118 elements built in. You can search by name, symbol, atomic number, category, phase, or block, click any element to inspect its atomic mass, group, period, and electron configuration, and visually compare families without leaving the page.

## How to Use

Use the search field to narrow the table, then optionally filter by category or phase. Click any tile to open its details card on the right. Reset returns the table to the default full view.
