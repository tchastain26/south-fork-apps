# Currency Converter Notes

Created: 2026.05.22
Status: Done

## What It Does

Converts between 34 world currencies using a static exchange rate table (rates circa May 2025). Enter an amount, pick source and destination currencies, and see the result instantly. Includes a swap button, per-rate display, and a quick-convert grid showing 1 unit of the source currency against all others.

## How to Use

1. Enter an amount in the Amount field.
2. Select the From and To currencies.
3. The result updates instantly.
4. Click ⇄ to swap currencies.
5. Click any chip in the quick grid to convert to that currency.
