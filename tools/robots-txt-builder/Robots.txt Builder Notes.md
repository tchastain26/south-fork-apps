# Robots.txt Builder Notes

Created: 2026.05.04
Status: Done

## What It Does

Builds a valid `robots.txt` file from simple form inputs instead of manual text editing. It supports allow and disallow rules, sitemap lines, crawl delay, host output, and one-click blocking for common AI crawlers.

## How to Use

Enter the site URL, any path rules, and optional sitemap or crawl settings. Turn on the AI crawler block if you want those bots fully disallowed, then copy or download the generated `robots.txt` file.
