# Piano Chords Notes

Created: 2026.05.09
Status: Done

## What It Does

Visual piano chord reference. Select any of 12 roots and 18 chord types (triads, 7ths, extended, sus, add9, 6th, etc.) to see the voicing highlighted on a two-octave piano keyboard. Root keys show darker green, chord tones show lighter green. Play button arpeggios the chord via Web Audio with a triangle wave. Octave selector shifts the playback range.

## How to Use

Pick a root, chord type, and octave. The keyboard highlights immediately. Hit Play to hear the arpeggio.
