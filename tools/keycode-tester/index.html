JavaScript Key Code Tester

Press any key to see its JavaScript event properties: key, code, keyCode, charCode, and modifier states. Free online keyboard event tester for developers.

JavaScript Key Code Tester is a free browser-based tool from South Fork Apps. There's nothing to install, no account to create, and no usage limit. Open the page, do the work, and move on.

How it works

  1. Open JavaScript Key Code Tester in any modern browser on desktop or mobile.
  2. Enter or paste your input into the tool's main field.
  3. Adjust any options shown on the page to match what you need.
  4. Copy or download the result and continue with your work.

Why use a browser tool

Browser tools beat installable apps when the job is small. You don't have to manage updates, sign in, or wait for a heavy program to load. JavaScript Key Code Tester runs entirely in your browser. Your input never leaves your device, no analytics watch what you type, and the page stops working the moment you close the tab.

Privacy and data

South Fork Apps tools process everything client-side in JavaScript. No server sees your data. Nothing is stored, logged, or sent anywhere. If you're working with sensitive content, you can verify by opening the page once, disconnecting from the internet, and watching JavaScript Key Code Tester keep working.
