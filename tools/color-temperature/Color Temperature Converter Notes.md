# Color Temperature Converter Notes

Created: 2026.05.22
Status: Done

## What It Does

Converts Kelvin color temperature to RGB, HEX, and HSL using Tanner Helland's algorithm. Includes a slider from 1000K–12000K, click-to-copy color values, and a reference table of common light sources (candlelight through clear blue sky). Click any reference row to jump to that temperature.
