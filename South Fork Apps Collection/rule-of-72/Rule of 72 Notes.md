# Rule of 72 Notes

Created: 2026.05.23
Status: Done

## What It Does

Rule of 72 estimates how long it takes money to double at a given annual return rate, compares that shortcut to exact annual compounding, and also shows rough timelines for tripling and quadrupling.

## How to Use

Enter an annual return rate or use the slider and preset buttons. Review the Rule of 72 estimate, exact doubling time, shortcut comparison, and milestone bars for doubling, tripling, and quadrupling.
