# Chord Transposer Notes

Created: 2026.05.09
Status: Done

## What It Does

Pastes a chord sheet (lead sheet, lyrics with chords, tab notation) and transposes all chord symbols to a target key. Detects standard chord names (C, Am, F#m7, Bb, etc.) with regex and shifts them by the correct number of semitones. Shows the semitone shift value. Supports preferring sharps or flats in output.

## How to Use

Paste chord text in the left box, select the original key and target key, and the right box updates in real time. Load the example to see a sample song sheet. Copy button exports the result.
