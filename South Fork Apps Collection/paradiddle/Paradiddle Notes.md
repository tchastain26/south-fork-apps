# Paradiddle Notes

Created: 2026.05.09
Status: Done

## What It Does

Drum rudiment trainer for all four paradiddle variations: Single, Double, Triple, and Paradiddle-Diddle. Each rudiment shows the full R/L sticking pattern with accent marks, a description, and a Select button to choose which rudiment to play. The Play button loops the selected pattern via Web Audio click sounds at adjustable BPM (40–200). The active beat highlights in real time as it plays. Includes a practice tips section.

## How to Use

Click Select on any rudiment, set BPM, hit Play. The active stroke highlights in green (R) or blue (L). Start slow and increase BPM as it becomes comfortable.
