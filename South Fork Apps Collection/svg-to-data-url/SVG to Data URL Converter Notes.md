# SVG to Data URL Converter Notes

Created: 2026.05.04
Status: Done

## What It Does

Converts raw SVG markup into a URL-encoded data URL that can be pasted straight into CSS or HTML. It also shows a live preview, strips optional XML and comment noise, and reports the byte impact of the conversion.

## How to Use

Paste SVG markup into the input area or load the sample. Leave the cleanup toggles on if you want smaller output, then copy either the full data URL or the ready-to-use CSS `background-image` line.
