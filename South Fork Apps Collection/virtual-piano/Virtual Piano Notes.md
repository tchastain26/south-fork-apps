# Virtual Piano Notes

Created: 2026.05.09
Status: Done

## What It Does

Playable two-octave piano keyboard (C4–B5) in the browser. Click keys or use keyboard shortcuts (ASDFGHJKL for white keys, WETYUOP for black keys). Web Audio API generates the tone using selectable waveforms (sine, triangle, square, sawtooth). Sustain duration and volume are adjustable via sliders. The display bar shows the last note played with octave number.

## How to Use

Click any key to play it, or use the keyboard shortcuts shown on each key. Adjust waveform, sustain, and volume in the control bar above. Works best with keyboard for fast playing.
