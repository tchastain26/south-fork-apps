# Ukulele Chords Notes

Created: 2026.05.09
Status: Done

## What It Does

SVG-based ukulele chord diagram browser in standard GCEA tuning. Includes 30 chords covering all common roots across Major, Minor, Dom 7, Maj 7, and Min 7 types. Diagrams show 4 strings left-to-right with open string circles, mute markers, fretted note dots, and barre chord bars. Filterable by root and type.

## How to Use

Filter by Root and Type dropdowns. Hover cards for highlight. String labels (G C E A) shown at bottom of each diagram.
