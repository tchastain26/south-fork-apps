# Color Blindness Simulator Notes

Created: 2026.05.03
Status: Done

## What It Does

See how a color appears under protanopia, deuteranopia, tritanopia, and achromatopsia. Free online color blindness tool.

## How to Use

Open the app in a browser. No account or install required — everything runs locally.
