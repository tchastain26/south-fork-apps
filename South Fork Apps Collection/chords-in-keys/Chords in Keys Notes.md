# Chords in Keys Notes

Created: 2026.05.09
Status: Done

## What It Does

Shows all 7 diatonic chords for any key and mode. Select a root note and one of 7 modes (Major, Natural Minor, Dorian, Phrygian, Lydian, Mixolydian, Locrian). Each chord card shows the chord name, Roman numeral, type (Major/Minor/Diminished), and harmonic function (Tonic/Subdominant/Dominant). Function cards are color-coded by role.

## How to Use

Select a root note and mode. The chord grid updates immediately. Hover cards for highlight. Tonic chords show green border, subdominant blue, dominant gold.
