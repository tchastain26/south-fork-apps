# Chromatic Scale Notes

Created: 2026.05.09
Status: Done

## What It Does

Interactive display of all 12 chromatic notes. Click any note to play it via Web Audio API and see its semitone number, octave, frequency in Hz, type (natural or accidental), and enharmonic equivalents. Octave selector lets you shift between octave 3, 4, and 5.

## How to Use

Select an octave, then click any note button to hear it and see its details in the info panel below the grid.
