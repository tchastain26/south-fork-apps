# Guitar Chords Notes

Created: 2026.05.09
Status: Done

## What It Does

SVG-based guitar chord diagram browser. Filter by root note and chord type. Diagrams show 6 strings left-to-right (low E to high E), muted strings (×), open strings (○), fretted notes (green dots), and barre chords (green bar). Includes 31 open and first-position chords across all common types.

## How to Use

Use the Root and Type dropdowns to filter. Hover any card for highlight. Diagrams scale responsively.
