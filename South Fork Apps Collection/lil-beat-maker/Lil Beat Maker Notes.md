# Lil Beat Maker Notes

Created: 2026.05.09
Status: Done

## What It Does

Full 8-track step sequencer with 16 or 32 steps per pattern. Tracks: Kick, Snare, HH Closed, HH Open, Tom Hi, Tom Lo, Clap, Cowbell. Each track has its own volume slider and color. Click cells to toggle beats on/off. Play/Stop button loops the pattern at an adjustable BPM (60–200). Includes Clear, Randomize, and Load Groove buttons. All sounds synthesized via Web Audio API — no samples needed.

## How to Use

Click cells to program beats. Hit Play to loop. Randomize generates a randomized groove. Load Groove loads a preset kick/snare/hi-hat pattern. Adjust BPM with the slider.
