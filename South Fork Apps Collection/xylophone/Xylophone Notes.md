# Xylophone Notes

Created: 2026.05.09
Status: Done

## What It Does

Playable virtual xylophone with 15 colored bars spanning two octaves (C4 through C6). Each bar is a different color by note letter. Click bars or use keyboard shortcuts (A–L for first octave, Q–Y for second) to play. Web Audio generates triangle/sine/square tones. Volume adjustable via slider. Current note name displays above the instrument.

## How to Use

Click bars or use keyboard shortcuts shown on each bar. Switch waveforms and adjust volume in the control bar above.
