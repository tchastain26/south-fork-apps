# Relative Pitch Notes

Created: 2026.05.09
Status: Done

## What It Does

Interval ear training tool. Each round plays two notes (ascending, descending, harmonic, or random) and presents multiple-choice interval names. Three difficulty levels control which intervals appear: Easy (P1/P4/P5/P8), Medium (all perfect + major/minor 3rds and 6ths), Hard (all 12 intervals). Tracks score, streak, and accuracy. Root note randomizes within the A3–A4 range. Auto-advances after each answer.

## How to Use

Select mode and difficulty. The interval plays automatically each round. Click an interval name to answer. Click "Play Interval" to replay before answering.
