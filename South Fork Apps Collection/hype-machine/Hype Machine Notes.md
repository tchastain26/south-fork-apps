# Hype Machine Notes

Created: 2026.05.05
Status: Done

## What It Does

Takes any mundane text and transforms it into over-the-top marketing hype copy. Three levels: Mild (subtle verb replacements and power adjectives), Turbo (adds opening declarations and hype inserts between sentences), and MAXIMUM OVERDRIVE (full transformation with random caps, closings, and pulsing button animation). Includes a fake "Hype Score" meter for fun. Copy button with feedback.

## How to Use

1. Select a hype level.
2. Type or paste anything mundane into the text area.
3. Press HYPE IT (or Cmd+Enter).
4. Copy the result and send it to someone who deserves it.
