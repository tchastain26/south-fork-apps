Time Signatures

Time signatures define how beats are grouped in a measure. The top number = beats per measure, the bottom number = which note value equals one beat.

Note Values Reference
Whole Note
4 beats
Half Note
2 beats
Quarter Note
1 beat
Eighth Note
½ beat
Sixteenth
¼ beat
Dotted Quarter
1.5 beats
