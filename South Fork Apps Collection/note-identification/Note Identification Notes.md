# Note Identification Notes

Created: 2026.05.09
Status: Done

## What It Does

Flashcard-style music note identification trainer. A note is drawn on a treble or bass clef staff using SVG — including proper stem direction, note head, and ledger lines when needed. User clicks the correct letter name from 4 choices. Tracks score, streak, and accuracy percentage. Three difficulty levels control the range of notes shown (lines only, lines + spaces, full range with ledger lines). Auto-advances after each answer.

## How to Use

Select clef and range, then identify notes as they appear. A "Hear note" button plays the pitch via Web Audio for additional ear training.
