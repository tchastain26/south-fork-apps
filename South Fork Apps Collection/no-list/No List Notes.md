# No List Notes

Created: 2026.05.05
Status: Done

## What It Does

A browser-based tool for maintaining a personal "No List" — a running record of commitments you've chosen to decline. Users type in anything they're saying no to, and it's added to a numbered list with a timestamp. Items persist in localStorage. Inspired by the concept behind David Sparks' iOS app of the same name.

## How to Use

1. Type something you're committing to decline in the input field and press Enter or click Add.
2. Items appear numbered in reverse-chronological order with the date added.
3. Click ✕ to remove an item when it's no longer relevant.
4. "Clear all" wipes the full list after a confirmation prompt.
5. Everything is stored locally in the browser — nothing leaves the device.
