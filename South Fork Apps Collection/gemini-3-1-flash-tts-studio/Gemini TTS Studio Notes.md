# Gemini TTS Studio Notes

Created: 2026.04.15
Status: Done

## What It Does

Generates high-quality AI speech using the Gemini 1.5 Flash TTS API. Supports single-voice and multi-voice (two speakers) modes. Includes directorial tags for controlling tone and delivery. Outputs a downloadable .wav file.

## How to Use

1. Enter your Google AI Studio API key
2. Choose single or multi-voice mode
3. Select voice profile(s)
4. Paste your script (supports directorial tags for expressive performance)
5. Generate and download the audio as .wav

- Requires a Gemini API key from Google AI Studio (not included)
