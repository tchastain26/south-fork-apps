# Ukulele Fretboard Notes

Created: 2026.05.09
Status: Done

## What It Does

Interactive ukulele fretboard showing all note names across 4 strings and 12 frets. Supports scale highlighting across multiple scale types and three tuning options (Standard GCEA, D Tuning ADF♯B, Low G). Root notes show in bright green, in-scale notes muted green, out-of-scale hidden. Fret markers at 3, 5, 7, 10, 12.

## How to Use

Select root, scale, and tuning. Fretboard updates immediately. Set root to "None" to see all notes without filtering.
