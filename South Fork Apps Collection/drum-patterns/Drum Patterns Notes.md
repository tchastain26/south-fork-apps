# Drum Patterns Notes

Created: 2026.05.09
Status: Done

## What It Does

Visual drum pattern reference and step sequencer. Includes 10 patterns across 6 genres (Rock, Funk, Jazz, Reggae, Hip-Hop, Latin). Each pattern shows a 16-step grid with rows for kick, snare, hi-hat, and other voices. Colors distinguish drum parts. Play button triggers Web Audio synthesis (noise for hi-hat/snare, sine for kick) at an adjustable BPM. Current step highlights during playback. Filter by genre.

## How to Use

Filter by genre, set BPM with the slider, click Play on any pattern to hear it loop. Click Stop to stop. Patterns can be played simultaneously.
