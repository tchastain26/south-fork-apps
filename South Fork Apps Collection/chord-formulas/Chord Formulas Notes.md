# Chord Formulas Notes

Created: 2026.05.09
Status: Done

## What It Does

Reference table for chord interval formulas grouped by type: triads, seventh chords, and extended/added chords. Each entry shows chord name, symbol, scale degree formula, interval description, and example notes in C.

## How to Use

Scroll through the three grouped sections. Example column hides on narrow screens.
