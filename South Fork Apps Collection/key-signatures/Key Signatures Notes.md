# Key Signatures Notes

Created: 2026.05.09
Status: Done

## What It Does

Filterable reference table for all 30 major and minor key signatures. Shows accidental count, type (sharps/flats), individual note names, and relative key for each entry.

## How to Use

Use the filter buttons (All, Major, Minor, Sharps, Flats, No Accidentals) to narrow the table. Rows highlight on hover.
