# Unit Circle Reference Notes

Created: 2026.05.24
Status: Done

## What It Does

This app gives Tucker a clean, interactive unit-circle reference with the standard trig angles, exact coordinate pairs, and exact sine, cosine, and tangent values. It also includes decimal approximations, quadrant sign reminders, and a clickable table for fast study or lookup.

## How to Use

Click a point on the circle, a quick angle button, or a row in the table to change the selected angle. Use the degrees and radians toggle to change the labels around the circle while keeping the same exact-value reference data.
