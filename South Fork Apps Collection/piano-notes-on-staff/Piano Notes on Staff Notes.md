# Piano Notes on Staff Notes

Created: 2026.05.09
Status: Done

## What It Does

Educational dual-staff piano visualizer. Click any key on a 4-octave piano (C2–C6) to see the note placed simultaneously on both treble and bass clef staves using SVG. Draws proper note heads, stems (direction follows convention), ledger lines for out-of-range notes, and accidental sharps where needed. Also shows note name, octave, MIDI number, and frequency. Plays the note via Web Audio.

## How to Use

Click any piano key. The note appears on both staves with correct placement, and plays automatically.
