# Image to Data URL Notes

Created: 2026.05.22
Status: Done

## What It Does

Converts any image file (PNG, JPEG, GIF, WebP, SVG, AVIF) to a Base64 data URL entirely in the browser. Shows a preview, file metadata, and dimensions. Outputs in four formats: raw data URL, CSS background-image, HTML img src, or Base64 only.

## How to Use

Drop an image onto the drop zone or click to browse. Choose the output format you need, then copy the result.
