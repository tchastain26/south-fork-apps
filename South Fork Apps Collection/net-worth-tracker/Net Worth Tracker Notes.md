# Net Worth Tracker Notes

Created: 2026.05.22
Status: Done

## What It Does

A session-based net worth calculator. Add named assets and liabilities with dollar amounts, and the app instantly shows total assets, total liabilities, net worth, and a proportional bar chart. All data lives in memory only — nothing is stored between sessions.

## How to Use

1. Type an asset name and amount, then click Add (or press Enter).
2. Do the same for liabilities.
3. The summary updates in real time. Click ✕ on any item to remove it.
