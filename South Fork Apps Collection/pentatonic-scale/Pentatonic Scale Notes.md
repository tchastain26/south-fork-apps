# Pentatonic Scale Notes

Created: 2026.05.09
Status: Done

## What It Does

Pentatonic scale explorer with dual major/minor mode. Select any root to see all 5 scale notes labeled by degree, highlighted on a two-octave piano keyboard, and displayed across 3 guitar box patterns per scale type (simplified fret grids). Includes an interval grid with degree labels, interval names, and semitone counts. Play button arpeggios the scale via Web Audio.

## How to Use

Select root and type (Major/Minor Pentatonic). All displays update instantly. Hit Play to hear the ascending scale.
