# BPM Counter Notes

Created: 2026.05.09
Status: Done

## What It Does

Tap-tempo BPM counter. Tap the button or press Space/Enter to the beat. Calculates BPM from the average interval between taps, displays the Italian tempo name (Andante, Allegro, etc.), and tracks min/max BPM for the session. Auto-resets after 3 seconds of silence.

## How to Use

Click the TAP button or press any key (Space/Enter) in rhythm. The BPM display updates after the second tap. Hit Reset or stop tapping for 3 seconds to start over.
