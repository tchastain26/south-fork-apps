# CSV Viewer Notes

Created: 2026.05.22
Status: Done

## What It Does

Paste CSV data and view it as a sortable, filterable table. Supports comma, tab, semicolon, pipe, and custom delimiters. Optional header row detection. Click any column header to sort ascending/descending. Live filter row searches across all columns.
