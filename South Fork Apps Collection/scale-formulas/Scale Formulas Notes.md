# Scale Formulas Notes

Created: 2026.05.09
Status: Done

## What It Does

Reference table for musical scale formulas grouped into four categories: Major/Natural Minor, Church Modes (all 7), Pentatonic and Blues, and Harmonic/Melodic Minor. Each entry shows the W/H step pattern with color-coded boxes, note count, scale degrees, and an example in C.

## How to Use

Scroll through the four sections. W = whole step, H = half step, WH = whole + half (used in pentatonic skips).
