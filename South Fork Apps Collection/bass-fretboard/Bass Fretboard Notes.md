# Bass Fretboard Notes

Created: 2026.05.09
Status: Done

## What It Does

Interactive bass guitar fretboard showing all note names across 4 strings and 24 frets (or 5 strings in 5-string mode). Supports scale highlighting across 8 scale types and 4 tunings (Standard EADG, Drop D, E♭ Standard, 5-String BEADG). Root notes show in bright green, in-scale notes in surface/bordered style, out-of-scale notes hidden. Fret markers at standard positions including double dots at 12 and 24.

## How to Use

Select root, scale, and tuning. Fretboard updates immediately. Set root to "None" to see all note names. Scroll horizontally to see all 24 frets.
