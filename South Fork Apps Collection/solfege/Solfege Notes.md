# Solfege Notes

Created: 2026.05.09
Status: Done

## What It Does

Interactive movable-do solfege reference. Click any of the 7 syllables (Do Re Mi Fa Sol La Ti) to hear its pitch via Web Audio and see its scale degree, interval name, note name in the selected key, and harmonic role. A chromatic map highlights the selected note's position across all 12 semitones. Key selector shifts the root to any of the 12 notes.

## How to Use

Select a key, then click any syllable button to hear it and see its details. The chromatic map at the bottom shows the note's position.
