## Ideas from Simon Willison's Tools (2026.04.29)

Good SFA candidates — simple, single-purpose, no server needed:

- **Reading Time Calculator** — estimate read time for pasted text
- **Transfer Time Estimator** — how long to transfer a file at a given speed
- **Date Calculator** — count days between two dates (including weekday-only option)
- **Encrypt/Decrypt Message** — share short encrypted messages via URL
- **Token Usage Calculator** — paste LLM log, get per-model token cost summary
- **Timestamp Converter** — Unix timestamp ↔ human-readable date (with timezone)
- **Extract URLs** — paste HTML or text, pull all links out
- **JSON to YAML / YAML to JSON** — quick format converter
- **SQL Pretty Printer** — paste messy SQL, get it formatted
- **Reading Level Analyzer** — paste text, get Flesch-Kincaid grade and readability score
